# Lunar Lander DQN Agent 🤖🌕

This repository contains a **Deep Reinforcement Learning agent** trained using **DQN** to play the Lunar Lander game (`LunarLander-v3`) in OpenAI Gymnasium.

---

## 🛠️ Features
- Trains a DQN agent to land the lunar module between flags safely.
- Continuous observation and discrete action space handled.
- Visualizes the trained agent in real-time.
- Compatible with CPU and GPU.
